# v0.0.2 実機再測定（2026-11-18）

Mac Studio M3 Ultra 512GB、RTX 5090 32GB・DDR5 128GB搭載PC、5GbE/SSH、WSL2上限96GB。公開v0.0.2のランチャーとHelperを使用し、Mac側にチャンク別時刻とリクエスト終了時のMLXピークメモリを記録する計測ラッパーを追加した。11層・32 Expert Bank・2048トークンチャンク・全ピン留め・先読みOFF・BF16一時KVとpooled KV再利用を共通とした。

各長さでウォームアップ1回、本計測5回。温度0・最大8生成トークンを指定し、実際の生成数は8K/32Kが4、64Kが8。キャッシュ保存を無効化し、全リクエストのキャッシュヒットは0だった。TTFTは最初の空でないストリーミング出力、Prefill専用時間はサーバーの完了計測から取得した。P10/P90は5標本を線形補間した。Prefillカウンターは入力数−1トークンを処理しており、速度は既存系列と同じく入力トークン数÷Prefill専用時間で算出した。

全18試行の生成ハッシュが各入力の9層参照と一致した。全330チャンクが11層を維持し、OOMとWSL2のスワップ使用は0だった。追加8層のPinned Expert重みはsafetensorsヘッダーから57,755,566,080 bytes（53.7890625GiB）と算出した。

NVIDIA総VRAMは約3秒間隔で採取した観測最大値。RTX側のMLX内部ピークは、Dockerログに前回起動の記録しか残っておらず取得できなかった。担当層数とチャンク数は今回のMac側受信記録で全件照合した。

起動中のWindows空きRAM最低は26.81GiB、コミット余裕最低は4.16GiB。測定完了後、ランチャーは正常終了し、専用Helperが停止したことを確認した。

今回の64K Prefill中央値は33.865秒。公開時の33.811秒・TTFT34.098秒は以前の別系列の結果として保持する。今回の計測ラッパーによるオーバーヘッドは個別には測定していない。生成ハッシュの比較対象は最大8トークンの出力であり、この再試験で全語彙logitsやKVキャッシュ全体は採取していない。

比較図のMac単体・v0.0.1の9層・M5 Maxの各数値は既存の測定系列であり、今回の11層再測定とは条件が異なる。M5 Maxの数値は参考・推定値で、出典と条件は未確認。
