# v0.0.2 hardware remeasurement — 2026-11-18

Measured on a Mac Studio M3 Ultra 512GB and an RTX 5090 32GB PC with 128GB DDR5 over 5GbE/SSH, with a 96GB WSL2 limit. The released v0.0.2 launcher and helper were used with a Mac metrics wrapper recording per-chunk timestamps and MLX peak memory once per request. All runs used 11 layers, 32 Expert Banks, 2,048-token chunks, fully pinned Experts, prefetch off, BF16 scratch and pooled KV reuse.

Each input length had one warm-up and five measured runs, with temperature zero and at most eight generated tokens. Actual output lengths were four tokens at 8K/32K and eight tokens at 64K. Cache storage was disabled, and all requests reported zero cache hits. TTFT is time to first nonempty streaming output. Prefill duration comes from the server's completion counter. P10/P90 use linear interpolation over five samples. The prefill counter covers input length minus one token. Throughput uses the full input token count divided by prefill duration, consistent with the earlier series.

All 18 generation hashes matched the nine-layer reference for the corresponding input. All 330 chunks retained 11 layers. No OOM or WSL2 swap use was observed. Checkpoint safetensors headers give 57,755,566,080 bytes (53.7890625GiB) of pinned Expert weights across the eight streamed layers.

Driver VRAM values are maxima observed at approximately three-second intervals. RTX MLX internal peaks were unavailable because Docker returned logs from the previous startup only. Every layer count and chunk count was checked against this run's Mac receive records.

Windows startup minimum available RAM was 26.81GiB, with minimum commit headroom of 4.16GiB. The launcher exited normally and the dedicated helper was confirmed stopped after measurement.

The new median 64K prefill was 33.865s. The earlier release figures of 33.811s prefill and 34.098s TTFT belong to a separate measurement series. Metrics-wrapper overhead was not independently measured. Hash checks cover the output of at most eight generated tokens. Full-vocabulary logits and complete KV caches were not captured in this remeasurement.

The Mac-only, v0.0.1 nine-layer and M5 Max points in the comparison diagram are from the earlier measurement series and have different conditions from this 11-layer remeasurement. M5 Max values remain reference/estimated figures, with source and conditions unverified.
